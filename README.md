# Метрики Холстеда для программы на Groovy

Лабораторная работа №1 по дисциплине «Метрология, стандартизация и сертификация в ИТ».
Парсер разбирает исходный текст на языке Groovy и считает шесть базовых метрик Холстеда
(η1, η2, N1, N2, f1j, f2i) и три расширенные (η, N, V).

## Как запустить

Открыть `index.html` в браузере. Ничего устанавливать и собирать не нужно.
Код анализируемой программы подставляется сразу, кнопки — «Рассчитать», «Пример»,
«Очистить», «Открыть файл» (`.groovy`), быстрый пересчёт — Ctrl+Enter.

## Состав

| Путь | Назначение |
|---|---|
| `Calculator.groovy` | анализируемая программа — консольный калькулятор на Groovy |
| `index.html`, `css/style.css` | интерфейс парсера |
| `js/tokenizer.js` | лексический разбор кода на Groovy |
| `js/halstead.js` | классификация лексем и расчёт метрик |
| `js/view.js` | вывод таблицы и расширенных метрик |
| `js/main.js` | обработчики интерфейса |
| `js/sample.js` | текст анализируемой программы для поля ввода |
| `Отчёт.docx`, `Отчёт.pdf` | отчёт по работе |
